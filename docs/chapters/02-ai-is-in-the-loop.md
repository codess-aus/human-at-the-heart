# Chapter 02 — AI Is in the Loop

We've crossed a threshold. AI is no longer a feature we toggle on — it's in the
loop of how software gets built, reviewed, shipped, and operated.

That changes the question we ask about it. For the last decade the debate was
*should* we use AI here? Today, in most engineering organisations, the answer
is already yes — Copilot is open in someone's editor right now, a model is
drafting a customer reply, an agent is opening a pull request.

So the live question is no longer **if**. It's **how**. How do we let these
systems assist us without ceding the judgment that should stay with people?
How do we keep the speed and lose the recklessness? How do we deploy AI
responsibly — not as a slogan, but as a daily engineering discipline?

That word — *responsibly* — is what the rest of this talk is about.
