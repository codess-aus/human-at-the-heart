# Chapter 09 — Copilot in Action

What does that loop look like inside a product? Here's how it shows up in
Copilot.

**Inline diffs you can read line by line.** When Copilot proposes a change,
it shows you the change — not a summary, not a "here's what I did", but the
actual diff. You scan it the same way you scan a colleague's pull request.

**Edits you accept, change, or discard.** Suggestions arrive as something you
can take whole, modify in place, or throw away — with no penalty for any of
those choices. That symmetry is the whole point. The product doesn't
emotionally invest in being right; it makes it easy for you to be right.

**Agent actions gated by human approval.** When Copilot moves from suggesting
into *acting* — running a command, opening a PR, modifying state outside the
editor — there's a deliberate approval step. The bar gets higher the further
the action is from "draft text in a buffer." That gate is the whole reason
agents can be useful in production at all.

These aren't accessibility features bolted on at the end. They're the product.
