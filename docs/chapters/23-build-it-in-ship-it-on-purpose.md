# Chapter 23 — Build It In, Ship It on Purpose

Back to where we started.

Trust is the ultimate feature — and like every other feature, it doesn't
happen by accident. It is *built in* and *shipped on purpose*. That phrasing
matters. Built in is a design choice; shipped on purpose is a discipline.

**Built in** means the trust properties are part of the architecture from
the first sprint. Explainability is in the data layer. Override is in the
state machine. Audit is on the wire. You don't add them later because you
can't — they shape decisions all the way down the stack.

**Shipped on purpose** means trust shows up in the release notes, the
roadmap, the OKRs, the bonus structure. Teams celebrate the trust feature
the same way they celebrate the performance feature. It's measured,
prioritised, and visible — not assumed to be someone else's job.

That's how a slogan becomes a product. Build it in. Ship it on purpose.
