# About

## The talk

**Trustworthy AI — Keeping Humans at the Heart of Intelligent Systems** is a
forty-five-minute talk on building AI-driven software that preserves human
judgment, creativity, and ethics.

It is delivered from a joint **GitHub and Microsoft** perspective — drawing on
the principles behind GitHub Copilot and Microsoft's Responsible AI Standard
— with practical takeaways developers can apply to their own products.

## The site

This site is the written companion to the talk. Each chapter pairs the slide
that appeared on screen with the talk track, rewritten for readers rather
than as speaker notes. Both light and dark modes are supported — the slide
hero images change with the palette.

The site is built with **[MkDocs Material](https://squidfunk.github.io/mkdocs-material/)**
and the slide images are rendered with **[Marp CLI](https://github.com/marp-team/marp-cli)**
from the source decks in [`slides/`](https://github.com/codess-aus/human-at-the-heart/tree/main/slides).
Both the site build and the slide rendering run on every push to `main` and
deploy to GitHub Pages.

## The decks

The original Marp decks are kept alongside the site source:

- [Dark theme deck](https://github.com/codess-aus/human-at-the-heart/blob/main/slides/trustworthy-ai-dark.md)
- [Light theme deck](https://github.com/codess-aus/human-at-the-heart/blob/main/slides/trustworthy-ai-light.md)

Both contain the same content with different palettes — pure black/white
backgrounds with vibrant pink, purple, cyan and green accents — designed to
meet AAA contrast and an 18-pixel minimum font floor.

## Accessibility

This site aims for WCAG 2.1 AA. If anything is hard to read, navigate, or
operate with a keyboard or screen reader, please
[open an issue](https://github.com/codess-aus/human-at-the-heart/issues) so it
can be fixed.
